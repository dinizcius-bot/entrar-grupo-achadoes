# 🦁 Achadões – Página de Entrada do Grupo WhatsApp

Este projeto é uma página simples e responsiva criada para facilitar a entrada no grupo oficial do Achadões no WhatsApp.  
A página replica o estilo visual exibido quando o link é aberto dentro do Instagram (In-App Browser), garantindo compatibilidade e facilidade de uso.

---

## 🔗 Link oficial do grupo

Entre no grupo Achadões pelo link abaixo:

👉 **https://chat.whatsapp.com/LE71t2Pe9R22E8L0P0kyBh?mode=hqrc**

---

## 🚀 Funcionalidades da página

- Botão para abrir diretamente o WhatsApp  
- Botão de fallback para abrir a página oficial do convite  
- Compatível com Instagram In-App Browser  
- Exibe o código do convite  
- 100% estática (HTML/CSS/JS)  
- Ideal para hospedagem via Vercel

## 💻 Como executar localmente

1. Baixe ou clone o repositório:

```bash
git clone https://github.com/seu-usuario/entrar-grupo-achadoes.git
```

2. Acesse a pasta:

```bash
cd entrar-grupo-achadoes
```

3. Abra o arquivo no navegador:

```bash
open index.html
```

Ou clique duas vezes no arquivo.

---

## 🚀 Deploy na Vercel

1. Suba o projeto para um repositório no GitHub  
2. Vá até a Vercel e clique em **New Project**  
3. Selecione o repositório  
4. Publique

A Vercel detectará automaticamente que é um projeto estático.
